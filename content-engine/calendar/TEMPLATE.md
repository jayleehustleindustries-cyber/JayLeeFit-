# TEMPLATE — weekly calendar output format

Copy everything between the lines into `weeks/week-NNN.md`, replace the
angle-bracket slots, delete nothing else. The first 4 columns match the
original `Content schedule for this week 001` Doc so downstream readers
(Codex, the 8:00 AM media-production block) keep working; the last 5
columns are the fields that block previously had to invent.

Field rules:
- **Day**: `Mon 6` style — weekday + day-of-month for the target week.
- **Type / Persona / Pattern**: only values defined in `HOOK-STANDARD.md`.
- **Hook**: the final hook text, in quotes.
- **Platform**: `IG+TT` (default), `IG+TT+YT` for Mon/Wed Mechanical
  (teaching content is the YouTube fit), unless Aaron says otherwise.
- **Asset Need**: an existing file name from `EHC Generated Assets`, or
  `Generate: <one-line visual description>`. Never blank.
- **Caption Angle**: one sentence telling the caption writer what the
  caption adds beyond the hook (the mechanism for Mechanical; the story
  behind the line for Villain/Filter). Not the caption itself.
- **CTA**: one of exactly three values — `Follow` (default),
  `Comment "<word>"` (lead-magnet weeks only), `Link in bio` (max 1/week).
