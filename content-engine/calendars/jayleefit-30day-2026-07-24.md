# JayLeeFit — 30-Day Content Calendar (2026-07-24 → 2026-08-22)

Brand: `jay_legacy_fit` / Everyday Hustle Co. — IG `@j_lee_is_me`,
TikTok `@jay_legacy_fit`, YouTube (Metricool brand id 6394851, tz
America/Los_Angeles).
Video backend: **Higgsfield** (stills proven at ~1.25 credits/1K image;
video + VO not yet piloted — see Rule 2). This calendar replaces any
earlier 30-day plan.

Goal, in the user's words: followers, attention, reach — **and** real
value in every post. The engine for that here: every post teaches one
usable thing (value), packaged in a ≤2s hook (attention), inside four
repeating weekly series (recognition → follows).

## RULES — agents read this block before touching any day below

1. **Pillars are law.** Every post maps to exactly one: (1)
   Fitness/Training, (2) Motivation/Mindset, (3) Personal Brand/Hustle,
   (4) Evidence-Based Performance. No generic fitness-influencer copy —
   QA rejects it (see content-engine/ARCHITECTURE.md §1a).
2. **No autonomous spend.** Higgsfield generation (image, video, VO)
   requires a cost preview (`get_cost:true`) and an explicit human
   go-ahead per batch. Video and VO are UNPILOTED — first use is a
   1-clip pilot, never a batch.
3. **No autonomous publishing.** Metricool `createScheduledPost` fires
   only on posts a human has approved. Drafts queue up; humans pull the
   trigger.
4. **State machine, no skips:** Idea → Scripting → Assets In Progress →
   QA Review → Scheduled → Published → Reviewed.
5. **QA gate (pass/fail):** pillar explicit; hook lands in first line /
   first 2 seconds; all assets Approved; no placeholder text.
6. **Analytics loop:** 24h/72h/1wk Metricool pulls per post; unavailable
   metric = blank, never a guess. Weekly retro proposes next ideas as
   `Needs CEO Review` — never auto-launched.
7. **No fake claims.** No invented client results, no fabricated stats;
   "evidence-based" means a citable source or your own logged data.
8. **Format discipline:** vertical 9:16, hook text on screen by 0:02,
   captions always, one CTA per post (follow OR save OR comment — not
   all three).

## Weekly engine (the repeating skeleton)

- **Mon — Proof Monday** (Evidence-Based Performance): one study or one
  logged personal metric → what to do with it.
- **Tue — Training Table** (Fitness/Training): one exercise or split,
  taught properly. Form cue everyone gets wrong.
- **Wed — Hustle Wednesday** (Personal Brand/Hustle): the
  fitness-meets-business lane — running JayLeeFit + the resale ops as
  one disciplined life.
- **Thu — Training Table II** (Fitness/Training): programming — sets,
  reps, progression, recovery.
- **Fri — Mindset Files** (Motivation/Mindset): discipline > motivation.
  DISCIPLINE FOCUS CONSISTENCY SUCCESS wall energy.
- **Sat — Client Corner / Q&A** (Fitness/Training): answer one real DM
  question or coach one common mistake. Comment-bait by design.
- **Sun — The Week in One Rep** (Motivation/Mindset): 20-30s recap +
  next week tease. Cheapest post of the week; recycles the week's
  clips.

## Why this shape wins reach

- **Four recognizable series** → viewers know what they followed for;
  follows convert better than one-off virals.
- **Comment engines** on Sat (Q&A/rate-my-split) → comments are the
  cheapest reach multiplier.
- **Day 29-30 payoff arc** → the calendar itself is a story ("watched
  the system for 30 days") that converts to coaching sign-ups.
- **Cost reality:** only 5 gated video days; everything else is stills,
  VO-over-B-roll, or recycled — the calendar survives even if video
  stays unpiloted (every [V] day has the [S] fallback: same hook as a
  designed still + caption carousel).
